# Screenshots

The landing page (`/index.html`) loads the screenshots below from this folder.
Save each image here with the **exact filename** so they appear in the gallery.

Map the screenshots you shared to these filenames:

| Filename               | Screenshot to use                                         |
| ---------------------- | --------------------------------------------------------- |
| `home.png`             | Home screen — "Amberwood … Resume Level 09 … Play"         |
| `gameplay.png`         | A puzzle in progress — "CHAPTER 1 · LEVEL 09" board        |
| `prism-challenge.png`  | The "PRISM CHALLENGE" puzzle (blue/red tangram board)      |
| `level-complete.png`   | The "Flawless! ⭐⭐⭐" level-complete screen                 |
| `world.png`            | "Your World" map — The Lantern Coast regions              |
| `daily.png`            | "Focus Prism" daily challenge screen                      |

Tips:
- PNG or JPG both work; keep them roughly portrait phone shape (9:19.5).
- Trimming the phone's status bar/nav bar is optional — the frame crops edges.
- Want different shots in the gallery? Edit the `<img src="...">` paths in
  `index.html` under the `#screens` section.
